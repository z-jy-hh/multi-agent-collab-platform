# AI Agent 概览(本地语料 · 演示用)

AI Agent 是能够感知环境、制定计划并调用工具来自主完成目标的软件系统。一个典型的 Agent
由四部分组成:大模型(LLM)作为推理内核、角色提示词定义职责边界、工具集扩展行动能力、
记忆系统沉淀上下文。

多 Agent 协同(Multi-Agent)把一个复杂任务拆给多个各有专长的 Agent:调度中心负责拆解与
派活,执行 Agent 并行工作,最后汇总产出。相比单 Agent 长上下文,多 Agent 的优势是上下文
隔离、职责单一、可并行、易定位问题。

常见协同拓扑包括:主管模式(supervisor)、流水线(pipeline)、辩论(debate)与单体(single)。
工程选型的核心不是"哪个最先进",而是"哪种控制流最匹配任务的可分解性"。

主管模式是多 Agent 系统里最常用的形态:一个主管 LLM 看任务、拆子任务、按各 Agent 的能力
画像匹配派活,收结果再汇总。能力画像通常包含擅长领域、可用工具与强项分数,派活时按
标签匹配与强项分加权打分,并把匹配理由记录进事件流,方便回放与审计。
